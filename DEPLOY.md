# Публикация в Timeweb App Platform

Проект настроен для статической публикации (`output: "export"`).

- Команда сборки: `npm run build`.
- Каталог публикации: `out` (не `.next` и не корень репозитория).
- Переменная окружения: `SITE_URL=https://mwsap.ru`.
- Команда запуска и порт для статического сайта не требуются.

После отправки изменений в подключённый репозиторий запустите повторный деплой.
Сборка создаёт `out/index.html`, файлы стилей, скрипты и изображения.
Изображения отдаются напрямую: сервер оптимизации Next.js не требуется.
